# Reversing-Offline-Search-Web Prompt Pack

AI 코딩 에이전트에게 이 폴더를 프로젝트 루트에 넣은 뒤 `MASTER_PROMPT.md` 내용을 전달하면 된다.

읽는 순서:
1. `AGENTS.md`
2. `REQUIREMENTS.md`
3. `CONTENT_PLAN.md`
4. `MASTER_PROMPT.md`
5. `state/progress.json`

핵심:
- Private GitHub repository: `Reversing-Offline-Search-Web`
- `dist/index.html` 완전 오프라인 실행
- 정확히 300개 글 계획
- Assembly Dictionary 포함
- `CALL` 같은 mnemonic 단독 검색 지원
- 툴 설치/사용/단축키
- 이미지/도식 로컬화
- 개발일지/진행상태 지속 저장
