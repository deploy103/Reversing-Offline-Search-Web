## 한 줄 요약
radare2 명령어는 접두 문자(`a`=analysis, `p`=print, `i`=info, `s`=seek 등)로 계열이 나뉘므로, 실전에서 가장 자주 쓰는 조합만 표로 외워두면 매번 문서를 찾아볼 필요가 없어진다.

## 언제 검색해야 하나
- radare2 세션 중 특정 명령어의 정확한 철자나 옵션이 기억 안 날 때
- 새 바이너리를 열 때마다 매번 같은 순서(분석 → 함수 목록 → 디스어셈블 → 문자열)로 반복하는 절차를 표로 빠르게 확인하고 싶을 때

이 문서는 각 명령의 상세 동작 원리를 다시 설명하지 않는다. 설치와 첫 세션 흐름은 [REV-0291 radare2 설치와 첫 명령](./rev-0291-radare2-install-first-command.md)을 먼저 참고할 것.

## 핵심 개념
radare2 명령은 접두 문자 하나로 계열이 정해진다 — 첫 글자만 봐도 "분석인지 출력인지 검색인지"를 구분할 수 있다.

## 가장 먼저 할 것 / 단계별 절차
새 바이너리를 열면 항상 같은 순서: `r2 -A ./chall`(또는 열고 나서 `aaa`) → `afl`로 함수 목록 확인 → `pdf @ main`으로 main 디스어셈블 → 필요하면 `iz`로 문자열. 아래 표는 이 순서에 필요한 명령들을 계열별로 정리한 것이다.

## 명령어/단축키
아래 계열별 표 전체가 명령어/단축키 목록이다.

## 분석(Analysis, `a` 계열)
| 명령 | 의미 |
|---|---|
| `aaa` | 전체 자동 분석(함수, xref, 타입 추정). 세션 시작 시 가장 먼저 실행 |
| `aa` | 기본 분석만(더 빠르지만 얕음) |
| `aaaa` | 심화 분석(느림, 큰 바이너리에서는 비추천) |
| `af` | 커서 위치를 함수로 인식시키기(분석이 놓친 함수를 수동 지정할 때) |
| `afl` | 찾은 함수 목록 전체 출력 |
| `afi` | 현재 함수의 상세 정보(인자 개수 추정, 크기 등) |
| `axt` | 현재 주소를 참조하는(xref to) 위치 목록 |
| `axf` | 현재 주소가 참조하는(xref from) 위치 목록 |

## 출력(Print, `p` 계열)
| 명령 | 의미 |
|---|---|
| `pdf` | 현재 함수 전체 디스어셈블리(Print Disassemble Function) |
| `pd 20` | 현재 위치부터 20개 명령어 디스어셈블리 |
| `px 64` | 현재 위치부터 64바이트 hex 덤프 |
| `pxw` | 4바이트(word) 단위로 hex 덤프 |
| `ps` | 현재 위치의 문자열 출력 |
| `pc` | 현재 바이트를 C 배열 리터럴 형태로 출력(패치/쉘코드 재사용 시 유용) |

## 파일/정보(Info, `i` 계열)
| 명령 | 의미 |
|---|---|
| `i` | 파일 요약 정보(포맷, 아키텍처, 엔트리 등) |
| `ii` | 임포트 함수 목록 (`readelf -d`/`objdump -T`에 대응) |
| `iz` | `.rodata` 등 데이터 섹션에서 문자열 추출 (`strings`에 대응) |
| `izz` | 파일 전체에서 문자열 추출(섹션 구분 없이, 더 넓게) |
| `is` | 심볼 테이블 (`nm`/`readelf -s`에 대응) |
| `ie` | 엔트리포인트 주소 |

## 이동(Seek, `s` 계열)
| 명령 | 의미 |
|---|---|
| `s main` | `main` 심볼 주소로 이동 |
| `s 0x1149` | 특정 주소로 이동 |
| `s+8` / `s-8` | 현재 위치에서 상대 이동 |
| `s sym.imp.puts` | 임포트 함수 스텁 주소로 이동 |

## 플래그/이름표(Flags, `f` 계열)
| 명령 | 의미 |
|---|---|
| `f` | 현재까지 등록된 플래그(이름표) 목록 |
| `f myname @ 0x1149` | 특정 주소에 이름표(IDA의 rename과 유사) 붙이기 |
| `fs` | 플래그 스페이스(카테고리) 목록 전환 |

## 검색(Search, `/` 계열)
| 명령 | 의미 |
|---|---|
| `/ password` | 문자열 "password" 검색 |
| `/x 4142` | hex 바이트 패턴 검색 |
| `/c` | 특정 opcode/명령어 패턴 검색 |

## Visual mode — 커맨드라인 안의 반쪽 GUI
```
V
```
로 진입하면 마우스 없이 방향키만으로 화면을 스크롤할 수 있는 반쪽짜리 GUI 모드로 들어간다. 실전에서 가장 많이 쓰는 것은 그 안에서 다시 `V`(대문자, 총 두 번)를 눌러 들어가는 **그래프 모드(VV)**다.

| 키 | 의미(Visual/그래프 모드 안에서) |
|---|---|
| `V` | Visual mode 진입 |
| `VV` (Visual 모드 안에서 `V` 한 번 더) | 그래프 모드(함수 제어 흐름 그래프, IDA 그래프 뷰와 유사) |
| `p` | 화면 표시 모드 순환(hex ↔ 디스어셈블리 ↔ 디버그 등) |
| 방향키 / `hjkl` | 이동 |
| Space | 그래프 모드에서 큰 블록/작은 블록 토글 |
| `q` | 현재 모드 나가기(여러 번 누르면 결국 프롬프트로 복귀) |

그래프 모드는 IDA의 함수 그래프 뷰와 거의 같은 정보(분기 블록, 조건 분기 화살표)를 커맨드라인 위에서 보여주므로, 조건문이 많은 함수의 흐름을 한눈에 보고 싶을 때 `pdf`보다 `VV`가 더 직관적이다.

## 미니 예제
```
$ r2 -A ./chall
[0x00001149]> afl
0x00001149    1 42   main
[0x00001149]> pdf @ main
```
세 줄이면 자동 분석 → 함수 목록 확인 → main 디스어셈블까지 끝난다.

## 흔한 실수
- 대소문자 혼동: `pdf`(함수 전체)와 `pDF`류는 다르며, radare2 명령어는 대소문자를 엄격히 구분한다.
- `aaa`를 생략하고 `afl`/`pdf`를 쳐서 빈 결과를 얻는 것 — 분석은 항상 명시적으로 먼저 실행해야 한다.
- Visual/그래프 모드에서 나가는 법을 몰라 `Ctrl+C`로 강제 종료하는 것 — `q`를 여러 번 누르면 단계적으로 빠져나온다.
