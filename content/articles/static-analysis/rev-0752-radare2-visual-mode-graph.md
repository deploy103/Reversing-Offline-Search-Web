## 한 줄 요약
radare2 프롬프트에서 `V`를 누르면 커맨드라인 안에서 동작하는 반쪽짜리 GUI인 Visual mode로 들어가고, 그 안에서 다시 `V`를 한 번 더 누르면(`VV`) IDA Graph View(REV-0150)나 Ghidra 그래프와 같은 개념의 **함수 제어 흐름 그래프**를 볼 수 있어, `pdf` 텍스트만으로는 잘 안 잡히던 조건 분기 구조를 한눈에 파악할 수 있다.

## 언제 검색해야 하나
- `pdf`로 디스어셈블리를 쭉 읽었는데 `jz`/`jnz`가 여러 번 중첩되어 있어서 어느 경로가 성공이고 어느 경로가 실패인지 텍스트만으로는 헷갈릴 때
- GUI 도구(IDA/Ghidra/Cutter) 없이 radare2만 있는 환경(SSH 세션, 컨테이너 등)에서도 그래프 형태로 분기를 보고 싶을 때
- `V`를 눌렀는데 화면이 낯설게 바뀌어서 어떻게 나가야 할지, 그래프는 어떻게 보는지 몰라 당황했을 때

## 핵심 개념
radare2는 원래 텍스트 프롬프트 기반 도구이지만, 터미널 안에서 화면을 전체 장악해 방향키로 스크롤하고 화면을 여러 모드로 전환할 수 있는 **Visual mode**를 내장하고 있다. `V` 한 글자로 진입하며, 진입 직후에는 하나의 화면 모드(기본은 디스어셈블리)만 보이지만 그 안에서 `p`를 누르면 hex/디스어셈블리/디버그 등 여러 표시 모드를 순환할 수 있다.

Visual mode 안에서 다시 `V`를 누르면(단축 표기로 `VV`) **그래프 모드**로 전환된다. 그래프 모드는 현재 함수를 기본 블록(basic block) 단위로 쪼개 박스로 그리고, 조건 분기의 두 갈래를 화살표로 연결해 보여준다. 이는 IDA의 Flow chart(REV-0150)나 Ghidra의 그래프 뷰와 동일한 개념 — "한 줄씩 읽는 대신 블록과 화살표로 구조를 본다"는 아이디어를 커맨드라인 환경에서 구현한 것이다.

그래프 모드에서는 통상적으로:
- 조건이 참일 때 이어지는 경로와 거짓일 때 이어지는 경로가 서로 다른 화살표/색으로 구분된다(터미널 색상 지원 여부에 따라 다름).
- Space 키로 블록을 "크게 보기/작게 보기(summarized)" 형태로 토글할 수 있어, 함수가 커도 전체 구조를 먼저 조망한 뒤 필요한 블록만 확대해서 볼 수 있다.
- 방향키/`hjkl`로 그래프 안을 이동하며 각 블록의 명령어를 확인한다.

GUI 도구가 없는 환경에서 이 기능은 특히 값어치가 크다. Cutter(REV-0293)의 Graph 뷰도 내부적으로는 같은 분석 엔진의 결과를 그리는 것이므로, `VV`로 보는 그래프와 근본적으로 같은 정보를 담고 있다.

## 화면/코드에서 보이는 징후
- `pdf` 결과에 `jz`, `jnz`, `je`, `jne` 같은 조건 분기가 3개 이상 중첩되어 있어 어떤 경로가 어디로 이어지는지 눈으로 따라가기 번거롭다.
- 함수 하나가 유난히 길고(`afl`에서 블록 수가 두 자릿수 이상), 텍스트로는 전체 흐름이 한눈에 안 들어온다.

## 가장 먼저 할 것
확인하고 싶은 함수로 `s`(seek)를 이용해 이동한 뒤 `V`를 눌러 Visual mode로 들어가고, 곧바로 `V`를 한 번 더 눌러(`VV`) 그래프 모드로 전환한다.

## 단계별 절차
1. `r2 -A ./chall`로 파일을 열고 `aaa`까지 마친다.
2. `s main`(또는 확인하려는 함수 이름/주소)으로 커서를 이동한다.
3. `V`를 눌러 Visual mode로 진입한다. 화면이 프롬프트에서 전체 화면 디스어셈블리 뷰로 바뀐다.
4. 그 상태에서 `V`를 한 번 더 눌러 그래프 모드(`VV`)로 전환한다. 현재 함수가 블록-화살표 그래프로 다시 그려진다.
5. 방향키 또는 `hjkl`로 그래프 안을 이동하며 각 블록 안의 명령어를 읽는다.
6. Space를 눌러 블록을 요약/확대 상태로 토글하며, 큰 함수는 먼저 요약 상태로 전체 구조를 본 뒤 관심 블록만 확대한다.
7. 확인이 끝나면 `q`를 여러 번 눌러 그래프 모드 → Visual mode → 원래 프롬프트 순서로 단계적으로 빠져나온다.

## 명령어/단축키
```
V           Visual mode 진입
VV          (Visual mode 안에서 V 한 번 더) 그래프 모드 전환
p           화면 표시 모드 순환(hex / disasm / debug 등)
Space       그래프 모드에서 블록 요약/확대 토글
hjkl / 방향키   그래프·화면 안 이동
q           현재 모드 나가기(반복하면 프롬프트로 복귀)
```

## 출력 해석
- 그래프의 각 박스는 하나의 기본 블록(중간에 분기 없이 순서대로 실행되는 명령어 묶음)이다. 박스 끝에서 뻗어나가는 화살표가 두 개면 조건 분기(`jz`/`jnz` 등)가 있다는 뜻이고, 하나면 무조건 분기(`jmp`) 또는 다음 블록으로 순차 진행이다.
- 화살표가 다시 위쪽 블록으로 돌아가는 형태(루프백)가 보이면 그 구간이 반복문이라는 뜻이다 — `for`/`while`이 컴파일된 결과가 이런 형태로 나타난다.
- 여러 블록에서 하나의 블록으로 화살표가 몰리는 형태는 여러 조건 분기가 결국 같은 지점(예: 공통 리턴 경로)으로 합류한다는 의미다.

## 흔한 실수
- Visual/그래프 모드에서 나가는 법을 몰라 `Ctrl+C`로 radare2 세션 자체를 강제 종료해버리는 것 — `q`를 여러 번 누르면 단계적으로 빠져나올 수 있다.
- `V`를 한 번만 누르고 그래프가 안 보인다고 당황하는 것 — 그래프는 `V`를 두 번(`VV`) 눌러야 나온다. 첫 `V`는 Visual mode 진입, 두 번째 `V`가 그래프 전환이다.
- 큰 함수에서 그래프를 처음부터 확대 상태로 보려다 화면이 복잡해 포기하는 것 — Space로 요약 상태를 유지한 채 전체 구조부터 먼저 훑는 것이 실전적이다.
- 그래프 모드가 IDA/Ghidra 그래프와 100% 똑같은 배치 알고리즘일 거라 기대하는 것 — 블록/화살표라는 개념은 같지만 레이아웃 방식은 도구마다 달라 보이는 모양이 다를 수 있다.

## 막혔을 때 다음 체크

- 함수 목록/xref 확인이 먼저 필요하면 → REV-0751 radare2로 함수 목록과 XREF 확인하기(afl, axt)
- 마우스 기반 GUI 그래프가 더 편하다면 → REV-0293 Cutter 설치와 기본 사용법
- IDA의 그래프 뷰 개념과 비교하고 싶다면 → REV-0150 IDA Graph View에서 분기 읽기

## 미니 예제
```
[0x00001149]> s main
[0x00001149]> V
```
전체 화면 디스어셈블리 뷰로 전환된 상태에서 `V`를 한 번 더 누르면, `main` 함수가 조건 분기마다 박스로 나뉜 그래프로 다시 그려진다. `cmp eax, 0` 다음 `jz`가 있는 블록에서 화살표가 두 갈래로 갈라지는 것을 확인하면, 참/거짓 각각의 경로가 어디로 이어지는지 텍스트 없이 그림만으로 짐작할 수 있다. 확인 후 `q`를 두 번 눌러 원래 프롬프트로 돌아온다.

## 출처/검증
- Visual mode(`V`)와 그래프 모드(`VV`) 진입 방식, Space를 통한 블록 요약 토글: radare2 공식 문서 "The Radare2 Book"(https://book.rada.re)의 Visual mode 관련 chapter 기준.
- 그래프 모드가 기본 블록/조건 분기를 시각화한다는 개념적 설명은 IDA Flow chart, Ghidra 그래프 뷰와 공통되는 "제어 흐름 그래프(CFG)" 일반 개념을 기준으로 정리했다.
- 단축키는 radare2 버전에 따라 일부 달라질 수 있어, 실제 세션에서 `V` 진입 후 `?`로 현재 버전의 도움말을 다시 확인할 것을 권장한다(2026-09-09 검증, 실기 재현은 하지 못함).
