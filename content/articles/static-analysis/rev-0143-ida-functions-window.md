## 한 줄 요약
Functions 창(단축키 `Ctrl+P`)은 바이너리 안의 모든 함수를 이름/주소/길이 등 컬럼으로 정리해서 보여주는 목록 창으로, 타이핑으로 즉시 필터링하고 더블클릭/Enter로 바로 이동할 수 있어 분석의 출발점으로 가장 많이 쓰인다.

## 언제 검색해야 하나
- 바이너리 안에 함수가 몇 개나 있는지, 어떤 이름들이 있는지 한눈에 보고 싶을 때
- 특정 이름(또는 이름의 일부)을 가진 함수를 빠르게 찾아 이동하고 싶을 때
- 가장 코드가 긴(=가장 복잡할 가능성이 높은) 함수를 찾고 싶을 때
- 어떤 함수가 사용자 코드이고 어떤 함수가 컴파일러/라이브러리가 자동으로 넣은 코드인지 구분하고 싶을 때

## 핵심 개념
Functions 창은 IDA가 인식한 **모든 함수의 목록**을 테이블 형태로 보여준다. 단순히 이름만 나열하는 게 아니라 여러 컬럼을 함께 보여주는데, 기본적으로 보이는 컬럼은 `Function name` 하나뿐인 경우가 많지만, 창 폭을 넓히거나 컬럼 헤더를 우클릭해서 더 많은 컬럼(`Segment`, `Start`, `End`, `Length`, `Locals`, `Arguments`, `R`, `F`, `L`, `S` 등)을 켤 수 있다.

- **Segment** — 함수가 속한 섹션 이름(`.text` 등).
- **Start / End** — 함수 시작/끝 주소.
- **Length** — 함수의 바이트 길이. 이 컬럼을 기준으로 정렬하면 코드가 가장 긴(대체로 가장 복잡한) 함수를 빠르게 찾을 수 있다.
- **Locals / Arguments** — IDA가 인식한 지역 변수 개수와 인자 개수(스택 프레임 분석 결과에 기반하므로, 분석이 틀리면 이 값도 부정확할 수 있다).
- **플래그 문자 컬럼(R/F/L/S 등)** — 함수 속성을 한 글자로 표시한다. 대표적으로 `L`은 라이브러리 함수(컴파일러가 넣은 런타임/표준 라이브러리 코드로, FLIRT 시그니처로 자동 인식됨)를 뜻하고, `F`는 프레임 포인터(BP/EBP/RBP)를 사용하는 함수, `R`은 "호출자에게 리턴하지 않는(non-returning)" 함수(예: `exit`류)를 표시하는 데 쓰인다. 정확한 문자 조합과 의미는 IDA 버전에 따라 약간 다를 수 있으므로, 창을 우클릭해서 나오는 컬럼 이름/툴팁으로 실제 설치된 버전에서 재확인하는 것이 안전하다.

목록에서 **분홍색(또는 회색/음영 처리)으로 표시되는 항목**은 대체로 라이브러리 함수다. IDA가 FLIRT 시그니처 매칭으로 "이건 컴파일러가 자동으로 넣은 C 런타임/표준 라이브러리 함수다"라고 판단한 것들이며, 색이 다르게 표시되어 사용자가 작성한 진짜 로직과 시각적으로 구분된다. 처음 분석할 때는 이렇게 색이 다른(라이브러리) 함수는 건너뛰고, 색이 다르지 않은 "일반" 함수 위주로 살펴보는 것이 효율적이다.

## 화면/코드에서 보이는 징후
- `Ctrl+P`를 누르면 별도의 모달/도킹 창으로 함수 이름과 여러 컬럼이 담긴 표가 뜬다.
- 목록 상단에 입력창이 있어서(또는 목록에 포커스를 둔 채로 바로) 타이핑을 시작하면 그 문자열이 포함된 함수 이름으로 목록이 즉시 좁혀진다.
- 일부 행이 다른 색(분홍/회색 계열)으로 표시되어 있다 — 라이브러리 함수임을 시각적으로 구분해주는 것이다.
- 컬럼 헤더를 클릭하면 그 컬럼 기준으로 오름차순/다시 클릭하면 내림차순 정렬된다.

## 가장 먼저 할 것
`Ctrl+P`로 Functions 창을 연 뒤, 먼저 전체 함수 개수를 확인한다(창 하단이나 스크롤바 크기로 대략 가늠 가능). 함수가 너무 적으면 패킹을, 대부분이 `sub_`로 시작하면 스트립(strip)을 의심하고, 그렇지 않다면 `Length` 컬럼 기준으로 정렬해서 가장 긴 함수 몇 개부터 살펴보는 것이 좋은 출발점이다.

## 단계별 절차

**1) 창 열기**

어느 화면에서든 `Ctrl+P`를 누른다(또는 메뉴 `View → Open Subviews → Functions`). 이미 열려 있다면 해당 탭을 클릭해서 포커스만 옮겨도 된다.

**2) 이름으로 필터링**

목록에 포커스가 있는 상태에서 원하는 이름의 일부를 타이핑하면(예: `check`, `verify`, `main`) 목록이 그 문자열을 포함하는 함수 이름으로 실시간 좁혀진다. 대소문자 구분 여부, 정확한 매칭 방식은 버전에 따라 다를 수 있으므로 몇 글자만 입력해서 결과를 보며 조정한다.

**3) 컬럼 켜기/정렬**

컬럼 헤더 영역에서 우클릭하면(또는 헤더 오른쪽 끝의 작은 화살표) 표시할 컬럼을 고를 수 있는 메뉴가 나온다. `Length`, `Locals`, `Arguments`, `R`, `F`, `L`, `S` 등을 켜서 원하는 정보를 표에 추가한다. 이후 `Length` 헤더를 클릭하면 함수 길이 기준으로 정렬되어, 가장 큰 함수를 맨 위(또는 맨 아래)에서 바로 찾을 수 있다.

**4) 함수로 이동**

원하는 함수 행을 더블클릭하거나, 선택 후 `Enter`를 누르면 IDA View(디스어셈블리) 화면이 해당 함수 시작 주소로 즉시 이동한다.

**5) 이름 바꾸기**

목록에서 함수를 선택하고 `N`을 누르면(또는 우클릭 → Rename) 바로 이 창에서 이름을 바꿀 수 있다. 함수 안으로 이동하지 않아도 목록 상태에서 여러 함수의 이름을 빠르게 정리할 수 있어 편리하다.

**6) 라이브러리 함수 구분**

색이 다르게(보통 분홍/회색 계열) 표시된 행은 라이브러리 함수다. 처음 훑어볼 때는 이런 행들을 건너뛰고, 일반 색상의 함수 — 즉 사용자(또는 원래 프로그램 작성자)가 직접 작성했을 가능성이 높은 함수 — 부터 우선 검토한다.

## 명령어/단축키
- `Ctrl+P` : Functions window 열기(이미 열려 있으면 해당 탭으로 포커스 이동하는 용도로도 사용됨)
- 타이핑 : 함수 이름 실시간 필터링
- `Enter` 또는 더블클릭 : 선택한 함수로 이동
- `N` : 선택한 함수 이름 변경(Rename)
- 컬럼 헤더 클릭 : 해당 컬럼 기준 정렬
- 컬럼 헤더 우클릭 : 표시할 컬럼 선택/조정

## 출력 해석
- 이름이 `sub_140001000`처럼 `sub_` + 주소 형태라면, IDA가 자동으로 붙인 기본 이름이며 원래 심볼 정보가 없었다는(스트립됐거나 애초에 그런 이름이 없었던) 뜻이다.
- 이름이 `_printf`, `_strcmp`처럼 실제 함수명이면서 색이 다르게 표시되면 FLIRT로 인식된 라이브러리 함수다.
- `Length`가 유난히 큰(예: 수천~수만 바이트) 함수는 여러 로직이 한 함수에 뭉쳐 있거나, 컴파일러가 인라인을 많이 한 결과일 수 있어 분석의 핵심 후보가 되는 경우가 많다.
- `Locals`/`Arguments` 값이 비정상적으로 크거나(수십 개) `0`으로만 나온다면 스택 프레임 분석이 실패했을 가능성이 있으므로 REV-0151(Positive SP Value 경고)이나 REV-0153(Stack Pointer 분석이 틀렸을 때) 쪽 문제를 의심해볼 수 있다.

## 흔한 실수
- 라이브러리 함수(색이 다른 행)까지 전부 하나하나 열어보면서 시간을 낭비하는 경우 — 색으로 구분되는 이유를 모르고 그냥 위에서부터 순서대로 다 보는 실수다.
- 필터 입력창에 아무것도 없는 상태에서 "필터가 안 먹힌다"고 착각하는 경우 — 실제로는 목록에 포커스가 안 가 있어서 타이핑이 다른 곳으로 들어가고 있을 수 있다. 목록 영역을 한 번 클릭해서 포커스를 준 뒤 타이핑한다.
- `Length` 정렬을 모른 채 함수 수백 개를 위에서부터 순서대로(대개 주소 순) 훑어보며 큰 함수를 찾으려 하는 경우 — 정렬 기능을 쓰면 몇 초 만에 끝난다.
- Functions 창에서 이름을 바꿔놓고, 실제 그 함수 코드는 열어보지도 않은 채 이름만 믿고 분석을 이어가는 경우 — 이름은 어디까지나 분석자가 붙인 가설일 뿐이므로 항상 코드로 검증해야 한다.

## 미니 예제
문자열 `"Access Denied"`를 참조하는 함수를 빠르게 찾고 그 함수의 대략적인 규모를 파악하는 흐름:

```text
1. Shift+F12로 Strings 창 열기 → "Access Denied" 검색/스크롤로 찾기
2. 해당 문자열에서 X 눌러 xref 확인 → 참조하는 함수 주소로 이동(Enter)
3. 그 함수 안에서 Ctrl+P로 Functions 창 열기 → 방금 이동한 함수 이름이 자동 선택되어 있는지 확인
4. Length 컬럼을 켜고 확인 → 이 함수가 몇 바이트짜리인지, 비슷한 이름의 다른 함수는 없는지 필터링해서 비교
```
