## 한 줄 요약
REV-0278에서 다룬 핵심 단축키(G/L/Ctrl+L/X/D/C/T/Y 등) 외에도, Ghidra에는 빠른 주석 입력(`;`), 변수 강조(가운데 클릭), 목록 필터링, 실행 취소(`Ctrl+Z`/`Ctrl+Y`), 창 복제 같은 고급 작업 편의 기능이 있어 큰 바이너리를 오래 붙잡고 분석할 때 훨씬 수월해진다.

## 언제 검색해야 하나
- Decompile/Listing 창에서 한 줄 주석을 매번 우클릭 메뉴로 다는 게 느리게 느껴질 때
- 변수 하나가 함수 안에서 어디어디에 쓰이는지 색으로 한눈에 보고 싶을 때
- Symbol Tree나 Functions 목록에 항목이 너무 많아서 이름으로 걸러 찾고 싶을 때
- 방금 한 이름 변경/타입 지정을 실수로 잘못 적용해서 되돌리고 싶을 때
- 두 함수를 나란히 띄워두고 비교하면서 분석하고 싶을 때

## 핵심 개념

### 빠른 EOL 주석 — `;`
Listing이나 Decompile 창에서 줄을 선택하고 `;`를 누르면 그 줄 끝에 바로 주석(End Of Line comment)을 입력하는 창이 뜬다. 우클릭 → `Comments` → `Set EOL Comment`로 가는 것과 같은 기능을 키 하나로 바로 부를 수 있다.

### 변수 강조(하이라이트) — 가운데 클릭
Decompile 창에서 변수나 레지스터를 마우스 가운데 버튼(휠 클릭)으로 클릭하면, 그 함수 안에서 같은 변수가 쓰인 모든 위치가 같은 색으로 강조된다. 다시 가운데 클릭하면 강조가 해제된다. 변수의 생존 범위(어디서 읽고 어디서 쓰는지)를 한눈에 훑을 때 매우 유용하다.

### 목록 필터링(Filter) — 깔때기 아이콘
Symbol Tree, Data Type Manager, Functions 목록 같은 트리/테이블 뷰 상단에는 대개 필터 입력창(또는 깔때기 모양 아이콘)이 있다. 여기에 이름 일부를 입력하면 그 텍스트를 포함하는 항목만 실시간으로 걸러서 보여준다. 함수/심볼이 수백 개 이상인 큰 바이너리에서 스크롤로 찾는 대신 이 필터를 먼저 쓰는 것이 훨씬 빠르다.

### Undo/Redo — Ctrl+Z / Ctrl+Y
이름 변경, 타입 재지정, 구조체 편집 등 대부분의 분석 작업은 `Ctrl+Z`(실행 취소)/`Ctrl+Y`(다시 실행)로 되돌리거나 재적용할 수 있다. 실수로 잘못된 이름/타입을 적용했을 때 처음부터 다시 하지 않아도 된다.

### 창 복제 — Clone Window
현재 보고 있는 Listing이나 Decompile 창 탭을 우클릭하면 `Clone Window`(또는 유사한 이름) 옵션으로 같은 종류의 창을 하나 더 띄울 수 있다. 이렇게 복제된 창은 서로 독립적으로 다른 함수를 보여줄 수 있어서, 호출하는 함수와 호출되는 함수를 화면 양쪽에 동시에 띄워두고 비교하며 분석할 때 유용하다.

### Copy Special — 다양한 형식으로 복사
바이트/주소를 다른 도구(파이썬 스크립트, 메모)에 붙여넣을 형식으로 복사하고 싶을 때, 선택 영역을 우클릭해 `Copy Special` 메뉴를 쓰면 hex 문자열, C 배열 등 여러 형식 중 골라서 클립보드에 복사할 수 있다.

## 화면/코드에서 보이는 징후
분석하던 함수의 변수 흐름이 복잡해서 눈으로 다 따라가기 힘들거나, Symbol Tree 스크롤이 끝없이 이어지거나, 실수로 이름을 잘못 바꿔서 원상복구하고 싶을 때 이 표를 참고한다.

## 가장 먼저 할 것
Decompile 창에서 변수 하나를 가운데 클릭해 강조 기능부터 시험해본다 — 가장 즉각적으로 효과를 체감할 수 있는 기능이다.

## 단계별 절차

**1) 빠른 주석**

Listing/Decompile에서 줄 선택 → `;` → 주석 입력 → Enter.

**2) 변수 강조**

Decompile 창에서 추적하고 싶은 변수를 가운데 클릭 → 같은 색으로 강조된 다른 위치들을 스크롤하며 확인 → 다시 가운데 클릭으로 해제.

**3) 목록 필터링**

Symbol Tree나 Data Type Manager 상단 필터 입력창에 이름 일부(예: `check`) 입력 → 일치하는 항목만 남는지 확인.

**4) 실행 취소 연습**

변수 이름을 하나 바꿔본 뒤 `Ctrl+Z`로 되돌리고, `Ctrl+Y`로 다시 적용해본다.

**5) 창 복제로 비교 분석**

현재 Decompile 탭 우클릭 → `Clone Window` → 복제된 창에서 다른 함수로 이동 → 원래 창과 나란히 배치해서 두 함수를 동시에 확인.

## 명령어/단축키
| 단축키/조작 | 동작 |
|---|---|
| `;` | 현재 줄에 EOL 주석 빠르게 입력 |
| 가운데 클릭(휠 클릭) | 변수/레지스터의 모든 사용 위치 강조(다시 클릭 시 해제) |
| 필터 입력창(깔때기 아이콘) | Symbol Tree/Data Type Manager/Functions 목록 실시간 필터링 |
| `Ctrl+Z` | 실행 취소(Undo) |
| `Ctrl+Y` | 다시 실행(Redo) |
| 탭 우클릭 → `Clone Window` | 같은 종류의 창을 복제해 다른 위치를 동시에 표시 |
| 우클릭 선택 영역 → `Copy Special` | hex/C 배열 등 다양한 형식으로 복사 |

## 출력 해석
- 가운데 클릭 강조는 함수 범위(scope) 안에서만 적용된다 — 다른 함수로 이동하면 강조가 풀린 것처럼 보이는데, 이는 정상이며 그 함수 안에서 다시 가운데 클릭해야 한다.
- 필터 입력창에 아무것도 안 걸리면(결과 0개) 오타이거나, 찾는 항목이 다른 Archive/카테고리에 있을 수 있다 — 필터 범위(전체 vs 현재 폴더)를 확인한다.
- `Ctrl+Z`를 여러 번 눌러도 되돌려지지 않는 특정 작업(예: 자동 분석 재실행 같은 대규모 작업)은 Undo 스택에 안 잡히는 경우가 있다.

## 흔한 실수
- 가운데 클릭 강조 기능을 몰라서 변수 하나의 흐름을 눈으로 스크롤하며 일일이 찾는 것.
- 필터 입력창의 범위(현재 폴더만 vs 전체 트리)를 착각해서 "분명히 있는데 필터에 안 걸린다"고 헷갈리는 것.
- 큰 규모의 되돌릴 수 없는 작업(예: Auto Analysis 재실행) 전에 프로젝트를 저장/백업해두지 않아 `Ctrl+Z`로도 복구가 안 되는 상황을 만드는 것.
- `Clone Window`로 여러 창을 띄운 뒤 어느 창이 어떤 함수를 보여주고 있는지 헷갈리는 것 — 탭 제목이나 창 배치를 신경 써서 정리해야 한다.

## 막혔을 때 다음 체크
- 핵심 단축키(G/L/Ctrl+L/X/D/C/T/Y) 자체가 헷갈리면 → REV-0278 Ghidra 핵심 단축키 치트시트.
- 구조체/타입 편집 자체가 궁금하면 → REV-0724 Ghidra Data Type Manager 빠른 참조.
- xref 추적이 필요하면 → REV-0160 Ghidra XREF 따라가기.
- 반복 작업을 아예 스크립트로 자동화하고 싶다면 → REV-0725 Ghidra 스크립트 API 빠른 참조(기초).

## 미니 예제
```text
1. Decompile 창에서 param_1 가운데 클릭 → 함수 안의 모든 param_1 사용 위치가 강조됨
2. 강조된 위치 중 의심스러운 줄에서 ; → "여기서 길이 체크함" 주석 입력
3. Symbol Tree 필터에 "verify" 입력 → verify_password 등 관련 함수만 추려짐
4. verify_password 우클릭(탭) → Clone Window → 새 창에서 그 함수를 계속 열어둔 채
   원래 창에서 main으로 돌아가 호출부와 나란히 비교
```

- EOL 주석 단축키(`;`), 변수 강조(가운데 클릭), 목록 필터 입력창, `Ctrl+Z`/`Ctrl+Y` Undo/Redo, 탭 `Clone Window`, `Copy Special` 기능은 Ghidra 공식 문서(Ghidra Help)와 공개된 Ghidra 사용 가이드/치트시트 자료에서 공통적으로 설명하는 기본 동작을 기준으로 정리했다(2026-09-09 검증).
- 일부 조작(필터 아이콘 위치, Clone Window 메뉴 문구)은 Ghidra 버전에 따라 표현이 다를 수 있어, 실제 설치본에서 우클릭 메뉴와 상단 툴바를 직접 확인할 것을 권장한다.
