## 한 줄 요약
REV-0275에서 다룬 12개 핵심 단축키(F5/F2/F7/F8/F9/X/N/G/Shift+F12/Ctrl+P/Y/Tab) 외에도, IDA에는 "방금 보던 위치로 돌아가기"(`Esc`/`Ctrl+Enter`), "중요한 위치를 표시해두기"(`Alt+M`/`Ctrl+M`), "그래프/텍스트 뷰 전환"(`Space`), "값/바이트 패턴 검색"(`Alt+T`/`Alt+B`/`Alt+I`) 같은 이동 전용 단축키가 따로 있어, 큰 바이너리를 여러 함수 오가며 분석할 때 시간을 크게 줄여준다.

## 언제 검색해야 하나
- 여러 함수를 오가며 분석하다가 "방금 보던 곳"으로 빠르게 되돌아가고 싶을 때
- 나중에 다시 봐야 할 중요한 주소 여러 개를 표시(북마크)해두고 싶을 때
- Graph view와 Text(flat) view를 마우스 없이 키보드만으로 전환하고 싶을 때
- 특정 문자열/바이트 시퀀스/상수 값을 코드 전체에서 검색하고 싶은데 어떤 단축키를 써야 할지 모를 때

## 핵심 개념

### 이동 히스토리 — Esc / Ctrl+Enter
IDA는 브라우저처럼 "이동 히스토리"를 기록한다. 어떤 함수를 보다가 xref(`X`)를 따라 다른 함수로 이동했다면, `Esc`를 눌러 바로 직전 위치로 되돌아갈 수 있고, 되돌아간 뒤 `Ctrl+Enter`를 누르면 다시 앞으로(되돌아가기 전 위치로) 이동한다.

### 위치 마킹 — Alt+M / Ctrl+M
분석 중 "여기는 나중에 다시 봐야겠다" 싶은 주소에서 `Alt+M`을 누르면 번호를 붙여 위치를 저장할 수 있다. `Ctrl+M`을 누르면 지금까지 마킹해둔 위치 목록이 뜨고, 목록에서 선택하면 바로 그 자리로 이동한다. 여러 개의 흥미로운 지점(암호 검증 함수, 파일 파싱 시작점 등)을 오가며 분석할 때 유용하다.

### Graph/Text 뷰 전환 — Space
디스어셈블리에서 `Space`를 누르면 현재 함수를 Graph view(분기 박스와 화살표)와 Text(flat) view(줄 단위 나열) 사이로 즉시 전환할 수 있다. 복잡한 분기 구조는 Graph로, 순차적으로 쭉 읽어야 할 때는 Text로 바꾸는 식으로 상황에 맞게 오간다.

### 검색 계열 — Alt+T / Alt+B / Alt+I
- `Alt+T` — 텍스트 검색(주석, 이름, pseudocode 텍스트 등에서 문자열 찾기)
- `Alt+B` — 바이너리(바이트 시퀀스) 검색. 특정 바이트 패턴(예: 시그니처, opcode 나열)을 찾을 때
- `Alt+I` — 즉시값(immediate value) 검색. 코드에 쓰인 특정 상수 값을 찾을 때

### 함수/세그먼트 경계 이동 — Home / End
`Home`/`End`는 현재 보고 있는 뷰(줄 목록)의 맨 처음/맨 끝으로 이동한다. `Ctrl+Home`/`Ctrl+End`는 더 큰 범위(세그먼트 또는 전체 주소 공간)의 시작/끝으로 이동하는 데 쓰인다.

## 화면/코드에서 보이는 징후
이 단축키들은 특정 코드 패턴이 아니라 "분석 흐름 자체"에서 필요해진다. 여러 함수를 오가다 길을 잃었거나, 나중에 다시 볼 위치가 늘어나고 있거나, 검색창을 매번 마우스로 여는 게 번거로워졌다면 이 표를 다시 훑어본다.

## 가장 먼저 할 것
지금 열려 있는 IDA에서 아무 함수나 열고 `Esc`와 `Ctrl+Enter`를 눌러 이동 히스토리가 어떻게 동작하는지 먼저 손으로 확인해본다.

## 단계별 절차

**1) 이동 히스토리 연습**

함수 A에서 `X`로 다른 함수 B로 이동 → `Esc`로 A로 복귀 → `Ctrl+Enter`로 다시 B로 이동.

**2) 마킹 연습**

중요 지점에서 `Alt+M` → 번호(0~9 등) 입력 → 다른 곳으로 이동 → `Ctrl+M` → 목록에서 방금 마킹한 위치 선택.

**3) 뷰 전환 연습**

Graph view 상태에서 `Space` → Text view로 바뀌는지 확인 → 다시 `Space`로 복귀.

**4) 검색 연습**

`Alt+B`로 특정 바이트 시퀀스(예: 알려진 매직 넘버 바이트열)를 검색해보고, `Alt+I`로 특정 상수값을 검색해 결과가 여러 xref 위치로 뜨는지 확인.

**5) 실전 조합**

큰 바이너리에서 여러 흥미 지점을 `Alt+M`으로 표시해두고, `Ctrl+M`으로 목록을 오가며 각 지점을 순서대로 정리하는 방식으로 실제 분석에 적용한다.

## 명령어/단축키
| 단축키 | 동작 |
|---|---|
| `Esc` | 이전 위치로 이동(뒤로 가기) |
| `Ctrl+Enter` | 다음 위치로 이동(앞으로 가기) |
| `Space` | Graph view ↔ Text view 전환 |
| `Alt+M` | 현재 위치 마킹(번호 지정) |
| `Ctrl+M` | 마킹된 위치 목록 열기 |
| `Alt+T` | 텍스트 검색 |
| `Alt+B` | 바이너리(바이트 패턴) 검색 |
| `Alt+I` | 즉시값(상수) 검색 |
| `Home` / `End` | 현재 뷰의 처음/끝으로 이동 |
| `Ctrl+Home` / `Ctrl+End` | 세그먼트/전체 주소 공간의 처음/끝으로 이동 |

## 출력 해석
- `Ctrl+M`으로 연 마킹 목록에는 번호, 주소, 마킹 당시 붙인 설명(있다면)이 함께 표시된다 — 설명 없이 번호만 있으면 나중에 헷갈리므로 마킹 시 짧은 설명을 붙이는 습관이 좋다.
- `Alt+B`/`Alt+I` 검색 결과가 여러 건이면, 검색 결과 창(또는 상태 표시줄)에서 다음/이전 결과로 넘어가는 방법(대개 검색을 다시 실행하거나 결과 목록을 이용)을 확인해야 한다.
- `Esc`를 눌렀는데 아무 반응이 없다면 이동 히스토리가 비어 있는(아직 다른 곳으로 이동한 적이 없는) 상태라는 뜻이다.

## 흔한 실수
- `Esc`가 "창 닫기"만 한다고 착각하고 안 써보는 것 — 디스어셈블리/Pseudocode 위에서는 이동 히스토리 뒤로가기로 동작한다.
- `Alt+M`으로 마킹만 해두고 설명을 안 붙여서, 나중에 `Ctrl+M` 목록을 봐도 무슨 의미였는지 기억을 못 하는 것.
- `Alt+T`(텍스트)와 `Alt+B`(바이트)를 헷갈려서 문자열을 바이트 검색창에 그대로 입력했다가 결과가 안 나오는 것.
- Graph view에서 `Space`를 눌렀는데 반응이 없어서 "키가 안 먹는다"고 착각하는 경우 — 포커스가 다른 창(Functions 등)에 가 있으면 안 먹힐 수 있으니 디스어셈블리 창을 한 번 클릭해 포커스를 준다.

## 막혔을 때 다음 체크
- 핵심 12개 단축키(F5/X/N/Y/Tab 등) 자체가 헷갈리면 → REV-0275 IDA 핵심 단축키 치트시트.
- Graph view 자체를 더 자세히 읽는 법이 궁금하면 → REV-0150 IDA Graph View에서 분기 읽기.
- 숫자 표현/enum 검색과 연계하고 싶다면 → REV-0149 IDA 숫자 표현 Signed Unsigned Hex 바꾸기.
- xref로 참조 위치를 추적하는 기본기가 필요하면 → REV-0145 IDA Xrefs와 X 키 사용법.

## 미니 예제
```text
1. Functions 창(Ctrl+P)에서 main 진입
2. X로 check_password 호출부로 이동
3. check_password 내부에서 Alt+M → "1" 지정 (암호 검증 지점 마킹)
4. Esc로 main으로 복귀
5. 다른 함수 parse_input으로 이동해 Alt+M → "2" 지정
6. Ctrl+M → 목록에서 "1"번 선택 → check_password로 즉시 복귀
```
여러 흥미 지점을 오가며 분석할 때 마킹과 이동 히스토리를 조합하면 함수 이름을 매번 검색하지 않고도 빠르게 왕복할 수 있다.

## 출처/검증
- 이동 히스토리(`Esc`/`Ctrl+Enter`), Graph/Text 뷰 전환(`Space`), 위치 마킹(`Alt+M`/`Ctrl+M`), 검색 계열(`Alt+T`/`Alt+B`/`Alt+I`), 뷰 경계 이동(`Home`/`End`/`Ctrl+Home`/`Ctrl+End`) 단축키는 Hex-Rays 공식 단축키 문서(docs.hex-rays.com/user-guide/configuration/shortcuts) 및 다수의 공개 IDA 단축키 정리 자료에서 공통적으로 보고되는 기본값 기준으로 정리했다(2026-09-09 검증).
- IDA는 `Options → Keyboard`에서 모든 단축키를 사용자가 재지정할 수 있으므로, 실제 설치본에서 이 표와 다르게 동작하면 해당 메뉴에서 실제 바인딩을 확인해야 한다.
