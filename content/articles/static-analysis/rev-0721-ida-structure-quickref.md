## 한 줄 요약
Pseudocode나 디스어셈블리에 `*(int *)(a1 + 8)`, `*(int *)(a1 + 0Ch)`처럼 같은 포인터에서 서로 다른 오프셋을 반복해서 읽는 코드가 보이면, IDA의 **Structures** 서브뷰(`Shift+F9`)에서 구조체를 직접 정의하고 그 포인터에 타입으로 적용해서 `a1->field_8`처럼 의미 있는 멤버 접근으로 바꿔 읽을 수 있다.

## 언제 검색해야 하나
- Pseudocode에서 같은 변수에 `+4`, `+8`, `+0Ch` 같은 오프셋이 반복적으로 등장할 때
- 오프셋 숫자만 봐서는 그 위치가 무엇을 의미하는지 기억하기 어려울 때
- 구조체 멤버를 직접 정의해서 `field_4` 같은 자동 생성 이름 대신 실제 필드 이름(`length`, `flag` 등)으로 바꾸고 싶을 때
- 소스가 없는 바이너리에서 힙에 할당된 커스텀 구조체(예: CTF 문제의 `struct player { int hp; int level; char name[32]; }`)의 레이아웃을 역으로 추정해서 문서화하고 싶을 때

## 핵심 개념

### Structures 서브뷰
`Shift+F9`를 누르면 **Structures** 창이 열린다. 이 창은 사용자가 직접 정의한 구조체/공용체(union) 목록을 관리하는 곳으로, IDA가 헤더에서 읽어온 표준 타입을 보여주는 Local Types(`Shift+F11`, REV-0723)와는 별개의 "사용자 정의 구조체 전용" 창이다.

### 구조체 추가와 멤버 편집
Structures 창에서 `Ins`(Insert) 키를 누르면 새 구조체/union 이름을 입력하는 대화상자가 뜬다. 구조체를 만든 뒤에는 그 구조체 안에서 다시 `Ins`를 눌러 멤버를 추가한다. 멤버 한 줄은 오프셋, 이름, 크기(타입)로 구성되며, `D` 키를 누르면 해당 멤버의 크기(byte/word/dword/qword)를 순환시켜 바꿀 수 있다. 이름은 `N`으로, 타입은 `Y`로 바꾸는 것이 다른 서브뷰와 동일하다.

### 포인터에 구조체 타입 적용하기
구조체를 만든 것만으로는 아무 효과가 없다. Pseudocode나 디스어셈블리에서 그 구조체를 가리키는 포인터 변수(예: `a1`) 위에 커서를 두고 `Y`(Set type)를 누른 뒤 `구조체이름 *` 형태로 타입을 지정해야 비로소 `a1->field_8`처럼 멤버 접근 표기로 바뀐다.

### Create struct — 디컴파일러가 구조체를 제안
Hex-Rays 디컴파일러는 한 포인터가 여러 오프셋으로 접근되는 패턴을 감지하면, Pseudocode 창에서 해당 변수를 우클릭했을 때 **Create struct**(또는 유사한 이름의 항목)를 제안하는 경우가 있다. 이 기능을 쓰면 접근된 오프셋들을 기반으로 구조체 뼈대를 자동 생성해주므로, 처음부터 손으로 오프셋을 하나씩 셀 필요 없이 자동 생성 결과를 다듬는 방식으로 작업할 수 있다.

### union — 같은 메모리를 다르게 해석
같은 오프셋이 상황에 따라 다른 타입으로 쓰이는 경우(예: 같은 4바이트가 어떤 코드 경로에서는 `int`, 다른 경로에서는 `float`로 읽힘) union을 만들어 처리한다. Structures 창에서 새 구조체를 만들 때 "Union" 옵션을 선택하면 일반 struct 대신 union으로 만들 수 있다.

## 화면/코드에서 보이는 징후
Pseudocode에서 `*(int *)(a1 + 4)`, `*(char *)(a1 + 8)`처럼 같은 포인터에 서로 다른 고정 오프셋이 여러 번 등장하거나, 디스어셈블리에서 `mov eax, [ecx+8]`, `mov [ecx+0Ch], edx`처럼 같은 베이스 레지스터에 여러 오프셋을 쓰는 코드가 반복되면 구조체 후보다.

## 가장 먼저 할 것
`Shift+F9`로 Structures 창을 열고, 코드에서 본 가장 큰 오프셋(예: `+0x20`)보다 넉넉한 크기로 구조체를 하나 만들어본다.

## 단계별 절차

**1) 오프셋 목록 정리**

Pseudocode나 디스어셈블리를 훑으며 같은 포인터에 대해 어떤 오프셋들이 등장하는지 먼저 메모한다(예: `+0`, `+4`, `+8`, `+0x28`).

**2) 구조체 생성**

`Shift+F9` → `Ins` → 이름 입력(예: `player_t`).

**3) 멤버 추가**

만든 구조체 안에서 `Ins`로 멤버를 하나씩 추가한다. 오프셋 순서대로 추가하면 편하고, 크기를 모르면 일단 `dword`(4바이트)로 넣은 뒤 `D`로 크기를 조정한다. 이름은 처음엔 `field_4`처럼 남겨도 되고, 역할이 파악되면 바로 의미 있는 이름으로 바꾼다.

**4) 포인터에 타입 적용**

Pseudocode에서 해당 포인터 변수(`a1` 등)를 클릭하고 `Y`를 눌러 `player_t *`로 타입을 지정한다.

**5) 결과 확인 및 반복**

`a1->unk_4`처럼 자동 이름이 붙은 멤버가 보이면, Structures 창으로 돌아가 그 멤버 이름/타입을 다시 다듬는다. 이 과정을 오프셋이 모두 의미 있는 이름으로 바뀔 때까지 반복한다.

## 명령어/단축키
| 단축키 | 위치 | 동작 |
|---|---|---|
| `Shift+F9` | 전역 | Structures 서브뷰 열기 |
| `Ins` | Structures 창 | 새 구조체/union 추가, 구조체 안에서는 새 멤버 추가 |
| `D` | Structures 창 | 멤버 크기(byte/word/dword/qword) 순환 |
| `N` | Structures 창 | 구조체/멤버 이름 변경 |
| `Y` | 디스어셈블리/Pseudocode | 포인터 변수에 `구조체명 *` 타입 적용 |
| 우클릭 → Create struct | Pseudocode | 오프셋 접근 패턴으로부터 구조체 자동 제안 |

## 출력 해석
- 타입 적용 후 `a1->field_8`처럼 보이면 성공적으로 구조체가 씌워진 것이다. `field_8`은 오프셋 8에 아직 이름을 안 붙였다는 뜻의 자동 이름이므로, `N`으로 실제 이름으로 바꿔주면 더 읽기 좋아진다.
- 구조체를 적용했는데도 여전히 `*(int *)(a1 + 8)` 형태로 남아 있다면, 타입 적용이 실제로 반영되지 않았거나(다른 변수에 적용했거나) 구조체 크기/오프셋이 실제 접근 패턴과 안 맞는 것이다.
- 구조체 멤버 크기의 합이 실제 코드에서 관찰되는 최대 오프셋보다 작으면 IDA가 경고하거나 멤버가 겹쳐 보일 수 있다 — 구조체 전체 크기를 다시 확인한다.

## 흔한 실수
- 구조체는 만들었지만 실제 포인터 변수에 타입을 적용(`Y`)하는 단계를 빼먹고 "왜 안 바뀌지"라고 헷갈리는 것.
- 멤버 크기를 실제와 다르게 지정해서 이후 멤버들의 오프셋이 전부 밀리는 것 — 특히 포인터(4바이트 vs 8바이트, x86 vs x64)를 헷갈리면 이 문제가 자주 생긴다.
- union이 필요한 상황(같은 오프셋을 다른 타입으로 재해석)인데 일반 struct로 만들어서 타입 충돌 경고를 겪는 것.
- 구조체 이름을 `struct_1`처럼 방치해서 나중에 이 구조체가 어떤 개념(플레이어 상태, 헤더 등)이었는지 잊어버리는 것.

## 막혔을 때 다음 체크
- 멤버 타입을 `int`가 아니라 포인터/배열로 지정해야 할 때 → REV-0148 IDA Y로 타입 지정하기.
- 표준 헤더에 이미 정의된 구조체(예: `struct timeval`)를 직접 만들지 않고 가져오고 싶다면 → REV-0723 IDA 타입 라이브러리(til) 빠른 참조.
- 구조체 멤버 중 하나가 상수 코드 값이라 이름표를 붙이고 싶다면 → REV-0722 IDA Enum 정의 빠른 참조.
- 구조체를 적용한 후에도 Pseudocode가 이상하게 보이면 → REV-0146 IDA F5 디컴파일과 Pseudocode 읽기.

## 미니 예제
```text
관찰된 패턴:
  *(int *)(a1 + 0)   // 항상 특정 값 비교
  *(int *)(a1 + 4)   // 레벨 값처럼 증가
  *(char *)(a1 + 8)  // 이름 문자열 시작으로 추정

Shift+F9 → Ins → 이름 "player_t" 입력
  Ins → offset 0, dword, 이름 hp
  Ins → offset 4, dword, 이름 level
  Ins → offset 8, char[32], 이름 name

Pseudocode에서 a1 위에 Y → "player_t *" 지정
결과:
  if ( a1->hp == 0 )
    ...
  a1->level += 1;
```

## 출처/검증
- Structures 서브뷰(`Shift+F9`)와 멤버 추가/크기 변경(`Ins`/`D`) 동작은 Hex-Rays 공식 문서(docs.hex-rays.com)의 단축키 레퍼런스 및 "Structures, unions, offsets" 관련 사용자 가이드 설명을 기준으로 정리했다(2026-09-09 검증).
- Pseudocode에서의 "Create struct" 자동 구조체 제안 기능은 Hex-Rays 디컴파일러의 공개된 사용자 가이드에서 설명하는 변수 재구성(retype/추론) 기능을 기준으로 서술했다. 정확한 메뉴 문구는 IDA 버전에 따라 다를 수 있으므로 실제 우클릭 메뉴에서 재확인할 것을 권장한다.
